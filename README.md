# BMI Calculator

A responsive BMI (Body Mass Index) Calculator web application developed using HTML, CSS, and JavaScript.

## Features
- Calculate Body Mass Index (BMI)
- Displays BMI category (Underweight, Normal, Overweight, Obese)
- Responsive and user-friendly interface
- Instant calculation

## Technologies Used
- HTML5
- CSS3
- JavaScript
